# 装进豆包、千问等聊天/办公软件

这些软件没有技能目录、不能派子智能体、不能读写你的磁盘，所以装法不是"放文件"，而是**把 [`prompts/chat-mode.zh-CN.md`](../prompts/chat-mode.zh-CN.md) 里那段提示词粘到它的自定义指令/智能体设定里**。粘完就是一个能用的「提示词精炼厂」。

---

## 三种装法（按软件能力从上往下选）

| 装法 | 适用 | 效果 |
| --- | --- | --- |
| **A. 建智能体 / 自定义指令**（首选） | 豆包、千问、Kimi、元宝、文心、星火、飞书、钉钉、ChatGPT、Claude | 一次配置，之后每次开对话都生效，不用重复粘贴 |
| **B. 每次开场粘贴** | 没有自定义入口的软件（部分网页版、手机 App） | 当次会话有效；把提示词存成便签/快捷短语，一键粘贴 |
| **C. 上传附件 + 一句话触发** | 支持读附件的（Kimi、豆包、千问、元宝） | 把提示词存成 `提示词精炼厂.txt` 上传，再说"按这个文件工作" |

判断标准很简单：**软件里有没有"智能体 / 角色设定 / 自定义指令 / 系统提示词"这类输入框**。有就用 A，没有就用 B 或 C。

---

## 1. 豆包（电脑版 / 网页版）

1. 打开 doubao.com 或豆包电脑版，登录。
2. 左侧栏点 **智能体**（有的版本叫「发现」→「创建智能体」）。
3. 点 **创建智能体**，填三项：
   - **名称**：`提示词精炼厂`
   - **介绍/描述**：`把模糊需求变成可直接执行的规格，再交付成品`
   - **角色设定 / 人设与回复逻辑**：粘贴 [`chat-mode.zh-CN.md`](../prompts/chat-mode.zh-CN.md) 里分隔线之间的全部内容
4. 保存 → 在"我的智能体"里打开它开始对话。
5. 验证：发一句「帮我整理下桌面」，它应当先问不超过 4 个带选项的问题，再给 10 区块规格，然后直接给方案——而不是反问一堆背景。

> 豆包电脑版还有"AI 编程"等专用入口，那些是代码沙箱，不需要装；本提示词用于普通对话与自建智能体。

---

## 2. 千问（通义千问 / Qwen 电脑版与 App）

1. 打开 qianwen.com 或千问桌面版，登录。
2. 进入 **智能体**（App 底部「发现」→「智能体」；网页左侧「智能体」）。
3. **创建智能体**：
   - 名称：`提示词精炼厂`
   - 简介：同上
   - **指令 / 提示词 / 角色设定**：粘贴 chat 版全部内容
4. 保存后从"我的智能体"进入。
5. 验证同豆包。千问对长提示词容忍度较好，但仍建议只粘贴核心段，别把整个 README 塞进去。

---

## 3. Kimi（月之暗面）

- 有 **Kimi+ / 智能体**：创建时把内容填到「提示词」框，保存即用。
- 只有普通对话时：上传 `提示词精炼厂.txt`（附件），开场说「按这个文件的规则工作，之后每条请求都走它的流程」。

---

## 4. 腾讯元宝

「我的」→ **创建智能体** → 「设定」里粘贴 chat 版内容 → 命名保存。元宝支持上传参考文件，可同时附上 `chat-mode.zh-CN.md` 作备份。

---

## 5. 文心一言 / 文心智能体平台

- App/网页：**创建智能体** → 「人设与回复逻辑」粘贴内容。
- 平台版（agents.baidu.com）：创建后可在「指令」里粘贴，还能挂知识库（把 `scorecard` 内容做成知识文件）。

---

## 6. 讯飞星火

**星火智能体** → 新建 → 「角色描述/指令」粘贴 → 发布。星火对"结构化输出"支持一般，建议在提示词末尾保留那句「按 10 个区块输出」。

---

## 7. DeepSeek 网页版 / App

没有自定义指令入口：

- 方案 B：把 chat 版存到输入法的快捷短语，开场粘贴一次。
- 若用 API/自建：直接把 chat 版当 `system` 消息，效果与智能体一致。

---

## 8. WPS AI / WPS 灵犀

WPS 的 AI 助手以文档内操作为主，没有长期生效的角色设定：

- 推荐 **方案 B**：在文档侧边栏 AI 对话开头粘贴一次，让它先产出规格，再让它按规格改文档。
- 团队版若有"自定义 AI 助手/智能体"，走 **方案 A**。
- 好处是它本来就能改文档：规格通过后可直接让它批量套格式。

---

## 9. 飞书（智能伙伴）/ 钉钉（AI 助理）

- 飞书：**智能伙伴 → 创建** → 「角色设定」粘贴 → 发布到群或工作台。
- 钉钉：**AI 助理 → 创建** → 「角色设定/指令」粘贴 → 添加到你或团队。
- 这两家都能设"开场白"，建议填：`把你的需求发我，我先出规格再干活。`

---

## 10. ChatGPT / Claude（作为对照）

- ChatGPT：**自定义指令（Custom instructions）** 第一栏粘贴；或做成 GPT（Instructions 字段）。
- Claude：**Projects → Project instructions** 粘贴；Claude 桌面版同样适用。
- 这两家支持文件与较长上下文，可以直接把 `SKILL.md` + `references/scorecard.md` 作为项目知识文件一起上传，效果接近完整版。

## 通用避坑清单

| 坑 | 现象 | 处理 |
| --- | --- | --- |
| 提示词被截断 | 智能体只记得前半段，提问规则失效 | 只粘 chat 版正文，别把 README/评分卡全文一起塞 |
| 平台把"角色设定"当闲聊 | 它开始扮演"精炼厂老板"而不是执行流程 | 在开头加一句「不要角色扮演，只按流程工作」 |
| 手机端入口不同 | 找不到"创建智能体" | 先在电脑网页版建好，App 里从"我的智能体"进入 |
| 每次新对话失忆 | 换会话后变回普通助手 | 必须从"我的智能体"进入，而不是新建普通对话 |
| 输出太长被截断 | 10 区块没写完就停 | 让它分段输出：「先给 1–5 区块，我说继续再给 6–10」 |
| 不肯先出规格 | 直接开始写代码/写文案 | 在结尾补一句「未通过自审前不许产出成品」 |

## 装完的验收话术（照抄发给它）

```text
帮我整理一下桌面文件
```

合格表现（三步）：

1. 最多问你一轮，每题带选项与默认值（不会反问"你的电脑是什么系统"这种能自己查的）；
2. 给出 10 区块规格，含 3–6 条可勾选验收；
3. **同一轮**里直接给出可执行的方案/脚本，而不是"规格已就绪，请确认"。

不合格就回到提示词里改这两句：`【第三阶段 · 自审（必须做，不许跳）】` 和 `【第四阶段 · 执行】`——绝大多数翻车都出在这两段被模型跳过了。

## 想要真正的"完整版"

聊天软件的天花板就在这里：它不能写文件、不能跑测试、不能用独立子智能体审计自己。要完整能力，装到能读 `SKILL.md` 的环境：

- DSH / Claude Code / Codex / Cursor / Windsurf / Cline / Copilot / Gemini CLI / Aider / Continue / opencode
- 逐家步骤见 [`integrations.zh-CN.md`](integrations.zh-CN.md)
